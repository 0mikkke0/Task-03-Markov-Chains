# Task 03: Text Generation with Markov Chains

This repository contains a lightweight statistical text generation algorithm built using **Markov Chains** via the `markovify` library.

## Project Overview
Markov Chains predict the probability of the next word or character in a sequence based strictly on preceding word states, generating synthetic text mimicking the training corpus.

## Project Structure
- `task3_markov_chain.py`: Script that constructs a second-order Markov model over a sample corpus to generate text sentences.
